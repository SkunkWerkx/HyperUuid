# R Binding Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A CRAN-shaped `r/` package, `hyperuuid`, whose hand-written C shim calls the thirteen C exports from a no_std Rust static library vendored into the source tarball, passing `R CMD check --as-cran` on this Mac.

**Architecture:** `r/src/rust/` is a wrapper crate `rcore` (`#![no_std]`, `staticlib`, `panic = "abort"`) over a rsynced copy of `rust/` at `r/src/rust/core/`; `tools/vendor.sh` makes that copy, stages the five binding corpus files and the `cargo vendor` tarball CRAN requires. `src/hyperuuid.c` owns hex parsing and formatting and the `.Call` entries; the R layer validates arguments, converts time and shapes results. Character results propagate `NA`; raw results are strict.

**Tech Stack:** R 4.6.1 (4.5 oldrel), testthat 3, jsonlite, roxygen2, devtools, lintr, bench; Rust 1.99.1 with the `x86_64-pc-windows-gnu` story left to CI.

**Spec:** `docs/superpowers/specs/2026-10-26-r-and-typescript-bindings-design.md` (section "R binding").

## Global Constraints

- Owner drives git: no commits; nothing in `rust/` changes; `corpus/*.json` is never edited.
- Package `hyperuuid`, `Depends: R (>= 4.2)`, `License: MIT + file LICENSE`, `SystemRequirements: Cargo (Rust's package manager), rustc`, `Config/testthat/edition: 3`, `Suggests: testthat (>= 3.0.0), jsonlite`.
- The only ABI surface is the thirteen prototypes in `src/core.h`, column-0 `uint32_t name(` / `int32_t name(` / `uint64_t name(` so `check_exports.py`'s `C_PROTOTYPE` matches.
- Layout argument everywhere: `layout = c("rfc", "sql")` through `match.arg`, codes 1 and 2. Variant strings: `"ncs"`, `"rfc9562"`, `"microsoft"`, `"future"`.
- Ids out are lowercase hyphenated. Ids in (`parse16` in C): 32 hex digits or 8-4-4-4-12, any case.
- Character, integer, logical and POSIXct results: `NA` in, `NA` out, element-wise; malformed in, `NA` out. Raw doors (`uuid_to_raw`, `uuid_from_raw`) and every *argument* (time, namespace, count) are strict and error. Errors are `stop()`/`Rf_error` with the messages pinned in the tasks.
- `time`: a `POSIXct`/`POSIXlt`/`Date` or a numeric in seconds since the Unix epoch; converted in R as `floor(seconds * 1000)`; length 1 (one `uuid_new_v7_batch` call) or `n` (n `uuid_new_v7` calls). Missing or non-finite elements error before any ABI call. `n > 67108864` with scalar time errors.
- No `printf`, `exit`, `abort`, `$(shell)` in the Unix `Makevars`, or non-API accessors in C. `CARGO_HOME` is under `src/` during the build; cargo runs with `-j 2`; `--offline` only when `src/rust/vendor.tar.xz` exists.
- Corpus: the five binding files by name, `v5.json`, `sql_order.json`, `sql_order_refused.json`, `timestamp.json`, `inspect.json`; a missing corpus or file is an error, never a skip.

## Review Focus

1. A `uuid_v7(n = 3, time = c(t1, t2))` length mismatch must error with a message naming both lengths, not recycle. Pinned in Task 2.
2. `uuid_to_raw(character(0))` must return a `raw` 16×0 matrix, and `uuid_from_raw(raw(0))` a `character(0)`, so empty data frames round-trip. Pinned in Task 3.
3. A `Date` for `time` (midnight UTC, not local midnight): the conversion must go through `as.POSIXct(x, tz = "UTC")` so a `Date` is unambiguous. Pinned in Task 2.
4. `uuid_v5(name = NA_character_)` propagates `NA` (name is data), while `uuid_v5(namespace = NA)` errors (namespace is an argument). Pinned in Task 4.
5. A factor passed as `x` (common from `read.csv`): must be treated as its character levels, not its integer codes. Pinned in Task 3 (`uuid_version(factor(V7)) == 7`).
